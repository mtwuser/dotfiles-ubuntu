2. **Universal `1:1:1` Symbiosis (`Theory/Spec <-> Verification/Test <-> Implementation/Corpus`)**: Read `docs/{guides,architecture,reference}/` first, tests second, and implementation last. 3. **Constants, SI/ISO Precision & Cut-Points (`N` vs `N ± 1`)**: Zero magic numbers, approximations, or raw slices. Use nominal constants (`*_CONTRACT_REV`, `MAX_*`, `MIN_*`, `DEFAULT_*`, `VALID_*`), exact SI/ISO units, and `N` vs `N ± 1` boundary cut-points.
